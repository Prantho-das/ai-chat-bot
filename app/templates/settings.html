Google Gemini API Key নেওয়া (সম্পূর্ণ ফ্রি)

১. প্রথমে Google AI Studio (aistudio.google.com) ওয়েবসাইটে যান।

২. আপনার যেকোনো জিমেইল একাউন্ট দিয়ে লগইন করুন।

৩. নীল রঙের "Create API key" বাটনে চাপ দিন এবং উৎপন্ন কী ( Key ) টি কপি করে নিন।

৪. এই পেজের "Step 2: Social APIs" ট্যাবে গিয়ে Gemini API Key বক্সে পেস্ট করে সেভ করুন।

2
Facebook Messenger & Post Comment ইন্টিগ্রেশন

১. Meta for Developers Console এ যান এবং আপনার একাউন্ট দিয়ে একটি Business App তৈরি করুন।

২. প্রোডাক্ট লিস্ট থেকে Messenger যুক্ত করে আপনার ফেসবুক পেজ যুক্ত করুন এবং Page Access Token তৈরি করে কপি করুন।

Facebook Webhook Callback URL:

http://127.0.0.1:8000/webhook/messenger

৪. Subscribed Fields কনফিগারেশন (ধাপ অনুযায়ী নির্দেশিকা):

  • `messages` (ইনবক্স মেসেজের জন্য): আপনি যখন মেটা ডেভেলপার কনসোলে Messenger Webhook কনফিগার করবেন, তখন অপশনগুলোর মধ্যে `messages` ফিল্ডের পাশে থাকা Subscribe বাটনে চাপ দিন। এর ফলে কাস্টমার পেজে ইনবক্স মেসেজ পাঠালে আপনার এআই বট সেটি পড়তে পারবে এবং উত্তর পাঠাতে পারবে।
  • `feed` (পোস্ট কমেন্টের জন্য): পেজের পোস্টের কমেন্টে অটো-রিপ্লাই দেওয়ার জন্য Webhooks -> Page (Feed) সেকশনে গিয়ে `feed` ফিল্ডের পাশে থাকা Subscribe বাটনে ক্লিক করুন। এর মাধ্যমে কাস্টমার পেজের পোস্টে কমেন্ট করার সাথে সাথেই বট কমেন্টের উত্তর দিবে।
