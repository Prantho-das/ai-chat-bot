📚 Google Calendar কিভাবে সেটআপ করবেন? (docs guide)
  1. Google Cloud Console-এ গিয়ে নতুন প্রজেক্ট তৈরি করুন।
  2. APIs & Services > Library থেকে Google Calendar API এনাবল করুন।
  3. Credentials > Create Credentials থেকে Service Account অথবা OAuth 2.0 Client ID সিলেক্ট করুন।
  4. Service Account তৈরির পর Keys অপশন থেকে JSON Key ডাউনলোড করে টেক্সট কপি করে "Service Account Credentials" বক্সে দিন।
  5. অথবা OAuth Client ID ও Secret বসিয়ে Refresh Token জেনারেট করে যুক্ত করুন।
