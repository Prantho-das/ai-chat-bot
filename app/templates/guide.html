Google Gemini API Key Setup

Free API Key setup for Gemini 3.6 AI Bot Engine

1. Navigate to Google AI Studio .

2. Sign in with your Google account.

3. Click "Create API key" and copy the generated API key string.

4. Go to Bot Settings > Social APIs, paste your key in the Gemini API Key field and save.

Google Calendar Integration Setup

Service Account Key integration for automated appointment scheduling

1. Open Google Cloud Console and create a project.

2. Enable the Google Calendar API from the API Library.

3. Create a Service Account under Credentials and generate a JSON Key.

4. Upload the JSON key file under Bot Settings > Calendar.
