1

Google Gemini API Key নেওয়া (সম্পূর্ণ ফ্রি)

বটের স্বয়ংক্রিয় উত্তরের জন্য বিনামূল্যে Gemini API কী যুক্ত করুন

১. প্রথমে Google AI Studio (aistudio.google.com) ওয়েবসাইটে যান।

২. আপনার যেকোনো জিমেইল একাউন্ট দিয়ে লগইন করুন।

৩. নীল রঙের "Create API key" বাটনে চাপ দিন এবং উৎপন্ন কী (Key) টি কপি করে নিন।

৪. Bot Settings > Step 2: Social APIs পেজে গিয়ে Gemini API Key বক্সে পেস্ট করে সেভ করুন।

2

Facebook Messenger & Post Comment ইন্টিগ্রেশন

ফেসবুক পেজ ইনবক্স ও পেজ কমেন্টে অটোমেটিক এআই রিপ্লাই সেটআপ

১. Meta for Developers Console এ যান এবং আপনার একাউন্ট দিয়ে একটি Business App তৈরি করুন।

২. প্রোডাক্ট লিস্ট থেকে Messenger যুক্ত করে আপনার ফেসবুক পেজ কানেক্ট করুন এবং Page Access Token জেনারেট করে সেভ করুন।

৩. Webhooks অপশনে গিয়ে Page সাবস্ক্রিপশন যুক্ত করুন এবং নিচের Callback URL ও Verify Token সেট করুন:

3

Google Calendar Integration Setup

গ্রাহকদের কথা অনুযায়ী গুগল ক্যালেন্ডারে মিটিং শিডিউল করার উপায়

১. Google Cloud Console-এ যান এবং নতুন একটি প্রজেক্ট তৈরি করুন।

২. APIs & Services > Library থেকে Google Calendar API এনাবল (Enable) করুন।

৩. Credentials > Create Credentials > Service Account দিয়ে একটি সার্ভিস একাউন্ট তৈরি করুন।

৪. সার্ভিস একাউন্টের Keys > Add Key > Create New Key > JSON অপশন দিয়ে ডেসটপে ডাউনলোড করুন।

৫. Bot Settings > Step 3: Calendar ট্যাবে ১-ক্লিকে JSON ফাইলটি আপলোড করে কানেক্ট সম্পন্ন করুন।

5

Facebook Commerce Catalog Sync

আপনার নলেজ বেসের প্রোডাক্টগুলো ফেসবুক কমার্স ক্যাটালগে অটো-সিঙ্ক করার উপায়

১. Meta Commerce Manager-এ যান এবং আপনার বিজনেসের জন্য একটি Catalog তৈরি করুন।

২. Data sources > Add items > Data feed সিলেক্ট করুন।

৩. Scheduled Feed বেছে নিন এবং নিচের Feed URL টি পেস্ট করুন (যেমন: প্রতিদিন স্বয়ংক্রিয়ভাবে সিঙ্ক হবে):
